## 1. Turso — база данных

Turso — распределённый SQLite. Бесплатный тариф: ~9 GB хранилища, 1 млрд чтений в месяц. Для 5–10 человек хватит на годы.

### 1.1. Регистрация

1. Открой https://turso.tech
2. Войди через GitHub
3. Создай организацию (по умолчанию — твой ник)
